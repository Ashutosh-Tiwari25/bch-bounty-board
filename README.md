# BCH Bounty Board

Built for **BCH BLAZE 2026** (14–22 Nov).

Post a creator bounty, collect submissions, and pay every winner in **one Bitcoin Cash transaction**, signed once through WizardConnect. The results page links to the transaction so anyone can verify the payout.

- Spec and plan: [`Preparation/SPEC.md`](Preparation/SPEC.md)
- Work that existed before the hackathon: [`Preparation/`](Preparation/)

## Run

```
npm install
npm run dev
```
